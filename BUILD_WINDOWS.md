# Збірка COSMOS у Windows EXE

## 1. Підготовка середовища

Відкрийте термінал PyCharm у корені COSMOS і виконайте:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements-build.txt
```

Рекомендовано збирати COSMOS у чистому віртуальному середовищі. Це не дозволить PyInstaller випадково додати непотрібні GUI-бібліотеки з інших проєктів.

## 2. Іконка

Необов'язково додайте файл:

```text
file_icon_exe/icon.ico
```

Якщо файла немає, COSMOS збереться зі стандартною іконкою Windows.

## 3. Збірка

```powershell
python build_exe.py
```

Готовий файл з'явиться тут:

```text
dist/COSMOS.exe
```

Скрипт автоматично додає головний каталог `frontend` та всі каталоги `apps/*/frontend`. Після додавання нового модуля список ресурсів у `build_exe.py` змінювати не потрібно.

## 4. Діагностична збірка

Якщо EXE запускається без вікна або одразу закривається, тимчасово замініть у `build_exe.py` параметр:

```text
--windowed
```

на:

```text
--console
```

Потім перебудуйте програму та запустіть `dist/COSMOS.exe` з термінала, щоб побачити текст помилки.

## 5. Повторна чиста збірка

`build_exe.py` уже використовує `--clean` і `--noconfirm`. За потреби каталоги `build` та `dist` можна видалити вручну перед повторною збіркою.
